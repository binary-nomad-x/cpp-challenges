# Diameter of Tree

- **Difficulty:** Easy
- **Topics:** Tree, DFS

## Problem Statement

Given a binary tree, find its diameter: the length of the longest path between any two nodes (edges count).

## Input Format

First line: n. Second line: n level-order values (-1 = null).

## Output Format

Print the diameter.

## Examples

**Example 1**

Input:
```
7
1 2 3 4 5 -1 -1
```

Output:
```
3
```

**Example 2**

Input:
```
5
1 2 3 4 5
```

Output:
```
3
```

**Example 3**

Input:
```
1
1
```

Output:
```
0
```


## Constraints

- 1 <= n <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
