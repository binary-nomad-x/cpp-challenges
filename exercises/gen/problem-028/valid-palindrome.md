# Valid Palindrome

- **Difficulty:** Easy
- **Topics:** Two Pointers

## Problem Statement

Given a string with mixed characters, determine whether it is a palindrome considering only alphanumeric characters and ignoring case.

## Input Format

First line: string s.

## Output Format

Print true or false.

## Examples

**Example 1**

Input:
```
A man, a plan, a canal: Panama
```

Output:
```
true
```

**Example 2**

Input:
```
race a car
```

Output:
```
false
```

**Example 3**

Input:
```
 
```

Output:
```
true
```


## Constraints

- 1 <= s.length <= 2*10^5

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
