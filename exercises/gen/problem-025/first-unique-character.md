# First Unique Character

- **Difficulty:** Easy
- **Topics:** Hashing

## Problem Statement

Given a string, return the index of the first non-repeating character, or -1 if it does not exist.

## Input Format

First line: string s.

## Output Format

Print the index.

## Examples

**Example 1**

Input:
```
leetcode
```

Output:
```
0
```

**Example 2**

Input:
```
loveleetcode
```

Output:
```
2
```

**Example 3**

Input:
```
aabb
```

Output:
```
-1
```


## Constraints

- 1 <= s.length <= 10^5, lowercase letters

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
