# Add Binary

- **Difficulty:** Easy
- **Topics:** Strings, Math

## Problem Statement

Given two binary strings, return their sum as a binary string.

## Input Format

First line: binary strings a and b separated by a space.

## Output Format

Print the binary sum.

## Examples

**Example 1**

Input:
```
11 1
```

Output:
```
100
```

**Example 2**

Input:
```
1010 1011
```

Output:
```
10101
```


## Constraints

- 1 <= a.length, b.length <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
