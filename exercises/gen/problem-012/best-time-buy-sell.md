# Best Time Buy Sell

- **Difficulty:** Easy
- **Topics:** Array, Greedy

## Problem Statement

Given daily prices of a stock, choose one day to buy and a later day to sell to maximize profit. Return 0 if no profit is possible.

## Input Format

First line: n. Second line: n space-separated prices.

## Output Format

Print the maximum profit.

## Examples

**Example 1**

Input:
```
6
7 1 5 3 6 4
```

Output:
```
5
```

**Example 2**

Input:
```
5
7 6 4 3 1
```

Output:
```
0
```


## Constraints

- 1 <= n <= 10^5, 0 <= prices[i] <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
