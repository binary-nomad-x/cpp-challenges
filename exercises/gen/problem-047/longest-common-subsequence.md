# Longest Common Subsequence

- **Difficulty:** Medium
- **Topics:** DP, Strings

## Problem Statement

Given two strings, return the length of their longest common subsequence.

## Input Format

First line: strings text1 and text2 separated by a space.

## Output Format

Print the length.

## Examples

**Example 1**

Input:
```
abcde ace
```

Output:
```
3
```

**Example 2**

Input:
```
abc abc
```

Output:
```
3
```

**Example 3**

Input:
```
abc def
```

Output:
```
0
```


## Constraints

- 1 <= text1.length, text2.length <= 1000

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
