# Min in Rotated Array

- **Difficulty:** Medium
- **Topics:** Binary Search

## Problem Statement

Given a sorted rotated array of distinct integers, find the minimum element.

## Input Format

First line: n. Second line: n distinct integers (rotated sorted).

## Output Format

Print the minimum.

## Examples

**Example 1**

Input:
```
5
3 4 5 1 2
```

Output:
```
1
```

**Example 2**

Input:
```
5
4 5 6 7 0 1 2
```

Output:
```
0
```

**Example 3**

Input:
```
1
11
```

Output:
```
11
```


## Constraints

- 1 <= n <= 5000

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
