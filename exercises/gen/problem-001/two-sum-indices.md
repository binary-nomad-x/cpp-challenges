# Two Sum Indices

- **Difficulty:** Easy
- **Topics:** Array, Hashing

## Problem Statement

Given an array of n integers and a target value, return the 0-based indices of the two numbers such that they add up to the target. Exactly one solution exists and you may not use the same element twice.

## Input Format

First line: n. Second line: n space-separated integers. Third line: target.

## Output Format

Print two indices in ascending order, space-separated.

## Examples

**Example 1**

Input:
```
5
2 7 11 15 3
9
```

Output:
```
0 1
```

**Example 2**

Input:
```
4
3 2 4 1
6
```

Output:
```
1 2
```


## Constraints

- 1 <= n <= 10^5, -10^9 <= nums[i], target <= 10^9

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
