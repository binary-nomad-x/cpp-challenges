# Find Needle Index

- **Difficulty:** Easy
- **Topics:** Strings

## Problem Statement

Given two strings haystack and needle, return the index of the first occurrence of needle in haystack, or -1 if needle is not part of haystack.

## Input Format

First line: haystack and needle separated by a space.

## Output Format

Print the index.

## Examples

**Example 1**

Input:
```
sadbutsad sad
```

Output:
```
0
```

**Example 2**

Input:
```
leetcode leeto
```

Output:
```
-1
```


## Constraints

- 1 <= haystack.length, needle.length <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
