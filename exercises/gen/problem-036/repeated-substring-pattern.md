# Repeated Substring Pattern

- **Difficulty:** Easy
- **Topics:** Strings, KMP

## Problem Statement

Given a string, check whether it can be constructed by taking a substring of it and appending multiple copies of the substring.

## Input Format

First line: string s.

## Output Format

Print true or false.

## Examples

**Example 1**

Input:
```
abab
```

Output:
```
true
```

**Example 2**

Input:
```
aba
```

Output:
```
false
```

**Example 3**

Input:
```
abcabcabcabc
```

Output:
```
true
```


## Constraints

- 1 <= s.length <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
