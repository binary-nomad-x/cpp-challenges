# Count Primes

- **Difficulty:** Medium
- **Topics:** Math, Sieve

## Problem Statement

Given an integer n, return the number of prime numbers strictly less than n.

## Input Format

First line: integer n.

## Output Format

Print the count.

## Examples

**Example 1**

Input:
```
10
```

Output:
```
4
```

**Example 2**

Input:
```
0
```

Output:
```
0
```

**Example 3**

Input:
```
1
```

Output:
```
0
```

**Example 4**

Input:
```
20
```

Output:
```
8
```


## Constraints

- 0 <= n <= 5*10^6

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
