# Remove Adjacent Duplicates

- **Difficulty:** Easy
- **Topics:** Stack

## Problem Statement

Given a string, repeatedly remove adjacent duplicate characters until none remain, then print the result.

## Input Format

First line: string s.

## Output Format

Print the final string.

## Examples

**Example 1**

Input:
```
abbaca
```

Output:
```
ca
```

**Example 2**

Input:
```
azxxzy
```

Output:
```
ay
```

**Example 3**

Input:
```
aababaab
```

Output:
```
ba
```


## Constraints

- 1 <= s.length <= 10^5

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
