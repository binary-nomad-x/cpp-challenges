# Merge Sorted Array

- **Difficulty:** Easy
- **Topics:** Two Pointers

## Problem Statement

Given two sorted arrays nums1 (size m+n) and nums2 (size n), merge nums2 into nums1 so that nums1 becomes sorted. nums1 has its first m elements filled, rest are placeholder 0s.

## Input Format

First line: m and n. Second line: m integers of nums1. Third line: n integers of nums2.

## Output Format

Print the merged sorted array of size m+n.

## Examples

**Example 1**

Input:
```
3 3
1 2 3
2 5 6
```

Output:
```
1 2 2 3 5 6
```

**Example 2**

Input:
```
1 0
1


```

Output:
```
1
```


## Constraints

- 0 <= m, n <= 200

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
