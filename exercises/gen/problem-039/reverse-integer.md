# Reverse Integer

- **Difficulty:** Medium
- **Topics:** Math

## Problem Statement

Given a signed 32-bit integer x, return x with its digits reversed. If reversing causes the value to go outside the 32-bit range, return 0.

## Input Format

First line: integer x.

## Output Format

Print the reversed integer.

## Examples

**Example 1**

Input:
```
123
```

Output:
```
321
```

**Example 2**

Input:
```
-123
```

Output:
```
-321
```

**Example 3**

Input:
```
120
```

Output:
```
21
```

**Example 4**

Input:
```
1534236469
```

Output:
```
0
```


## Constraints

- -2^31 <= x <= 2^31 - 1

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
