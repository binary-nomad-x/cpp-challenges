# Two Sum Sorted

- **Difficulty:** Easy
- **Topics:** Two Pointers, Binary Search

## Problem Statement

Given a 1-indexed sorted array of integers and a target, return the 1-based indices of the two numbers that add up to the target. Exactly one solution exists.

## Input Format

First line: n. Second line: n space-separated sorted integers. Third line: target.

## Output Format

Print two indices (1-based) in ascending order, space-separated.

## Examples

**Example 1**

Input:
```
4
2 7 11 15
9
```

Output:
```
1 2
```

**Example 2**

Input:
```
3
2 3 4
6
```

Output:
```
1 3
```


## Constraints

- 2 <= n <= 3*10^4, array is sorted ascending

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
