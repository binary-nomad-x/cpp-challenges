# Merge Intervals

- **Difficulty:** Medium
- **Topics:** Sorting

## Problem Statement

Given n intervals, merge all overlapping intervals and print the non-overlapping sorted result, one interval per line as 'start end'.

## Input Format

First line: n. Next n lines: 'start end'.

## Output Format

Print merged intervals, one per line.

## Examples

**Example 1**

Input:
```
4
1 3
2 6
8 10
15 18
```

Output:
```
1 6
8 10
15 18
```

**Example 2**

Input:
```
2
1 4
0 4
```

Output:
```
0 4
```


## Constraints

- 1 <= n <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
