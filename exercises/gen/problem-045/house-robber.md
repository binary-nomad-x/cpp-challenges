# House Robber

- **Difficulty:** Medium
- **Topics:** DP

## Problem Statement

Given an array of non-negative integers representing money in each house, rob the maximum amount without robbing two adjacent houses.

## Input Format

First line: n. Second line: n space-separated integers.

## Output Format

Print the maximum amount.

## Examples

**Example 1**

Input:
```
4
1 2 3 1
```

Output:
```
4
```

**Example 2**

Input:
```
5
2 7 9 3 1
```

Output:
```
12
```


## Constraints

- 1 <= n <= 100, 0 <= nums[i] <= 400

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
