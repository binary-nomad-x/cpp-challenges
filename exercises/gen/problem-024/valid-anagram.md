# Valid Anagram

- **Difficulty:** Easy
- **Topics:** Hashing

## Problem Statement

Given two strings, determine whether one is an anagram of the other.

## Input Format

First line: strings s and t separated by a space.

## Output Format

Print true or false.

## Examples

**Example 1**

Input:
```
anagram nagaram
```

Output:
```
true
```

**Example 2**

Input:
```
rat car
```

Output:
```
false
```


## Constraints

- 1 <= s.length, t.length <= 5*10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
