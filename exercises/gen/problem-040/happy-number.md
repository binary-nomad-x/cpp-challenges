# Happy Number

- **Difficulty:** Easy
- **Topics:** Hashing, Math

## Problem Statement

A happy number eventually reaches 1 when replaced by the sum of the squares of its digits; otherwise it loops endlessly. Determine whether n is happy.

## Input Format

First line: integer n.

## Output Format

Print true or false.

## Examples

**Example 1**

Input:
```
19
```

Output:
```
true
```

**Example 2**

Input:
```
2
```

Output:
```
false
```


## Constraints

- 1 <= n <= 2^31 - 1

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
