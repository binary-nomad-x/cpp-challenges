# Single Number

- **Difficulty:** Easy
- **Topics:** Bit Manipulation

## Problem Statement

Given a non-empty array of integers where every element appears twice except for one, find that single one. Your algorithm should run in linear time and use constant extra space.

## Input Format

First line: n. Second line: n space-separated integers.

## Output Format

Print the single element.

## Examples

**Example 1**

Input:
```
3
2 2 1
```

Output:
```
1
```

**Example 2**

Input:
```
5
4 1 2 1 2
```

Output:
```
4
```


## Constraints

- 1 <= n <= 3*10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
