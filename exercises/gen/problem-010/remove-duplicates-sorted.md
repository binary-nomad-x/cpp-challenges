# Remove Duplicates Sorted

- **Difficulty:** Easy
- **Topics:** Two Pointers

## Problem Statement

Given a sorted array, remove the duplicates in place so each element appears once and return the new length. Print the first k elements.

## Input Format

First line: n. Second line: n space-separated sorted integers.

## Output Format

Print k followed by the first k elements of the modified array.

## Examples

**Example 1**

Input:
```
5
1 1 2 2 3
```

Output:
```
3 1 2 3
```

**Example 2**

Input:
```
3
1 1 1
```

Output:
```
1 1
```


## Constraints

- 0 <= n <= 3*10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
