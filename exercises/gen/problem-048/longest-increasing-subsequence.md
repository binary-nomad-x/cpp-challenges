# Longest Increasing Subsequence

- **Difficulty:** Medium
- **Topics:** DP, Binary Search

## Problem Statement

Given an integer array, return the length of the longest strictly increasing subsequence.

## Input Format

First line: n. Second line: n space-separated integers.

## Output Format

Print the length.

## Examples

**Example 1**

Input:
```
8
10 9 2 5 3 7 101 18
```

Output:
```
4
```

**Example 2**

Input:
```
6
0 1 0 3 2 3
```

Output:
```
4
```

**Example 3**

Input:
```
7
7 7 7 7 7 7 7
```

Output:
```
1
```


## Constraints

- 1 <= n <= 2500, -10^4 <= nums[i] <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
