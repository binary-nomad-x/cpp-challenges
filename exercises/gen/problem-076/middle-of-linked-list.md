# Middle of Linked List

- **Difficulty:** Easy
- **Topics:** Linked List, Two Pointers

## Problem Statement

Given a singly linked list, return the middle node value. If two middles exist, return the second.

## Input Format

First line: n. Second line: n list values.

## Output Format

Print the middle value.

## Examples

**Example 1**

Input:
```
5
1 2 3 4 5
```

Output:
```
3
```

**Example 2**

Input:
```
6
1 2 3 4 5 6
```

Output:
```
4
```


## Constraints

- 1 <= n <= 100

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
