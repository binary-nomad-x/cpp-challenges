# Erase Overlap Intervals

- **Difficulty:** Medium
- **Topics:** Greedy, Sorting

## Problem Statement

Given intervals, find the minimum number of intervals you must remove to make the rest non-overlapping.

## Input Format

First line: n. Next n lines: 'start end'.

## Output Format

Print the minimum removals.

## Examples

**Example 1**

Input:
```
4
1 2
2 3
3 4
1 3
```

Output:
```
1
```

**Example 2**

Input:
```
3
1 2
1 2
1 2
```

Output:
```
2
```

**Example 3**

Input:
```
1
1 2
```

Output:
```
0
```


## Constraints

- 1 <= n <= 10^5

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
