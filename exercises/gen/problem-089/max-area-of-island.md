# Max Area of Island

- **Difficulty:** Medium
- **Topics:** Graph, DFS

## Problem Statement

Given a binary grid, find the maximum area of an island (4-directional land cells).

## Input Format

First line: m and n. Next m lines: n characters (0/1).

## Output Format

Print the maximum area (0 if no land).

## Examples

**Example 1**

Input:
```
4 5
11000
11000
00100
00011
```

Output:
```
4
```

**Example 2**

Input:
```
1 1
0
```

Output:
```
0
```

**Example 3**

Input:
```
5 5
11110
11010
11000
00000
00000
```

Output:
```
9
```


## Constraints

- 1 <= m, n <= 50

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
