# Maximum Product Subarray

- **Difficulty:** Medium
- **Topics:** DP, Array

## Problem Statement

Given an integer array, find the contiguous subarray with the largest product and return the product.

## Input Format

First line: n. Second line: n space-separated integers.

## Output Format

Print the maximum product.

## Examples

**Example 1**

Input:
```
4
2 3 -2 4
```

Output:
```
6
```

**Example 2**

Input:
```
3
-2 0 -1
```

Output:
```
0
```

**Example 3**

Input:
```
5
-2 3 -4
```

Output:
```
24
```


## Constraints

- 1 <= n <= 2*10^4, -10 <= nums[i] <= 10

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
