# Valid Parentheses

- **Difficulty:** Easy
- **Topics:** Stack

## Problem Statement

Given a string containing only ()[]{}, determine whether the input string is valid (brackets closed by same type in correct order).

## Input Format

First line: string s.

## Output Format

Print true or false.

## Examples

**Example 1**

Input:
```
()
```

Output:
```
true
```

**Example 2**

Input:
```
()[]{}
```

Output:
```
true
```

**Example 3**

Input:
```
(]
```

Output:
```
false
```

**Example 4**

Input:
```
([)]
```

Output:
```
false
```


## Constraints

- 1 <= s.length <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
