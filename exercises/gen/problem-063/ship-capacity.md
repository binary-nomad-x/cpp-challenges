# Ship Capacity

- **Difficulty:** Medium
- **Topics:** Binary Search

## Problem Statement

Packages on a conveyor must be shipped within d days, loading each day in order without exceeding ship capacity. Find the minimum capacity.

## Input Format

First line: n and d. Second line: n package weights.

## Output Format

Print the minimum capacity.

## Examples

**Example 1**

Input:
```
6 2
3 2 2 4 1 4
```

Output:
```
9
```

**Example 2**

Input:
```
5 3
1 2 3 4 5
```

Output:
```
6
```


## Constraints

- 1 <= days <= weights.length <= 5*10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
