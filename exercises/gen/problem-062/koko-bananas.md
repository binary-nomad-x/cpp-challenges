# Koko Bananas

- **Difficulty:** Medium
- **Topics:** Binary Search

## Problem Statement

Koko loves bananas; there are n piles, eating speed k means k bananas/hour from one pile per hour. Find the minimum k to eat all bananas within h hours.

## Input Format

First line: n and h. Second line: n pile sizes.

## Output Format

Print the minimum speed.

## Examples

**Example 1**

Input:
```
5 7
30 11 23 4 20
```

Output:
```
20
```

**Example 2**

Input:
```
5 6
30 11 23 4 20
```

Output:
```
23
```


## Constraints

- 1 <= n <= 10^4, piles[i] <= 10^9, n <= h <= 10^9

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
