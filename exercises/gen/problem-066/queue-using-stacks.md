# Queue Using Stacks

- **Difficulty:** Easy
- **Topics:** Stack, Design

## Problem Statement

Implement a first-in-first-out queue using two stacks, supporting push, peek, pop, and empty. Process q queries.

## Input Format

First line: q. Next q lines: push x | pop | peek | empty.

## Output Format

Print each pop/peek result, and true/false for empty, each on its own line.

## Examples

**Example 1**

Input:
```
8
push 1
push 2
peek
pop
empty
```

Output:
```
1
1
false
```


## Constraints

- 1 <= q <= 100

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
