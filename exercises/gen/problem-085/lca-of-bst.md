# LCA of BST

- **Difficulty:** Medium
- **Topics:** Tree, BST

## Problem Statement

Given a BST (level-order, -1 = null) and two node values p and q, find their lowest common ancestor value.

## Input Format

First line: n p q. Second line: n level-order values.

## Output Format

Print the LCA value.

## Examples

**Example 1**

Input:
```
7 2 8
6 2 8 0 4 7 9
```

Output:
```
6
```

**Example 2**

Input:
```
7 2 4
6 2 8 0 4 7 9
```

Output:
```
2
```


## Constraints

- 2 <= n <= 10^5, p != q, both exist

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
