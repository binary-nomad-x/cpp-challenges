# Plus One

- **Difficulty:** Easy
- **Topics:** Array, Math

## Problem Statement

Given a large integer represented as an array of digits, increment it by one and return the resulting array of digits.

## Input Format

First line: n. Second line: n digits space-separated (no leading zeros unless the number is 0).

## Output Format

Print the digits space-separated.

## Examples

**Example 1**

Input:
```
3
1 2 3
```

Output:
```
1 2 4
```

**Example 2**

Input:
```
4
4 3 2 1
```

Output:
```
4 3 2 2
```

**Example 3**

Input:
```
2
9 9
```

Output:
```
1 0 0
```


## Constraints

- 1 <= n <= 100

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
