# Backspace Compare

- **Difficulty:** Easy
- **Topics:** Stack, Two Pointers

## Problem Statement

Given two strings with '#' meaning a backspace character, compare whether they are equal after processing backspaces.

## Input Format

First line: strings s and t separated by a space.

## Output Format

Print true or false.

## Examples

**Example 1**

Input:
```
ab#c ad#c
```

Output:
```
true
```

**Example 2**

Input:
```
ab## c#d#
```

Output:
```
true
```

**Example 3**

Input:
```
a#c b
```

Output:
```
false
```


## Constraints

- 1 <= s.length, t.length <= 200

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
