# Longest Palindromic Substring

- **Difficulty:** Medium
- **Topics:** Expand Around Center, DP

## Problem Statement

Given a string, return the longest palindromic substring in it. If multiple have the same max length, return any.

## Input Format

First line: string s.

## Output Format

Print the longest palindromic substring.

## Examples

**Example 1**

Input:
```
babad
```

Output:
```
bab
```

**Example 2**

Input:
```
cbbd
```

Output:
```
bb
```

**Example 3**

Input:
```
a
```

Output:
```
a
```


## Constraints

- 1 <= s.length <= 1000

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
