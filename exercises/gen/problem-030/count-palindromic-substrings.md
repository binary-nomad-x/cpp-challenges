# Count Palindromic Substrings

- **Difficulty:** Medium
- **Topics:** Expand Around Center

## Problem Statement

Given a string, count how many palindromic substrings it has (substrings with equal start and end).

## Input Format

First line: string s.

## Output Format

Print the count.

## Examples

**Example 1**

Input:
```
abc
```

Output:
```
3
```

**Example 2**

Input:
```
aaa
```

Output:
```
6
```

**Example 3**

Input:
```
fdsklf
```

Output:
```
6
```


## Constraints

- 1 <= s.length <= 1000

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
