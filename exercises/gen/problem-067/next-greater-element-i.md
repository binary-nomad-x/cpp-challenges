# Next Greater Element I

- **Difficulty:** Easy
- **Topics:** Stack, Hashing

## Problem Statement

Given nums1 (subset of nums2), find the next greater element for each element of nums1 in nums2; use -1 if none.

## Input Format

First line: n1 n2. Second line: nums1. Third line: nums2 (all distinct).

## Output Format

Print n1 answers space-separated.

## Examples

**Example 1**

Input:
```
4 4
4 1 2
1 3 4 2
```

Output:
```
-1 3 -1
```

**Example 2**

Input:
```
3 4
2 4
1 2 3 4
```

Output:
```
3 -1
```


## Constraints

- 1 <= nums1.length <= nums2.length <= 1000

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
