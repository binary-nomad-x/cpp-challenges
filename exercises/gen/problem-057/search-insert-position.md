# Search Insert Position

- **Difficulty:** Easy
- **Topics:** Binary Search

## Problem Statement

Given a sorted array and a target, return the index if target is found; otherwise return the index where it would be inserted to keep the array sorted.

## Input Format

First line: n and target. Second line: n sorted integers.

## Output Format

Print the index.

## Examples

**Example 1**

Input:
```
4 5
1 3 5 6
```

Output:
```
2
```

**Example 2**

Input:
```
4 2
1 3 5 6
```

Output:
```
1
```

**Example 3**

Input:
```
4 7
1 3 5 6
```

Output:
```
4
```


## Constraints

- 1 <= n <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
