# Meeting Rooms II

- **Difficulty:** Medium
- **Topics:** Heap, Sorting

## Problem Statement

Given meeting time intervals, find the minimum number of conference rooms required.

## Input Format

First line: n. Next n lines: 'start end'.

## Output Format

Print the minimum rooms.

## Examples

**Example 1**

Input:
```
3
0 30
5 10
15 20
```

Output:
```
2
```

**Example 2**

Input:
```
2
7 10
2 4
```

Output:
```
1
```


## Constraints

- 1 <= n <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
