# First and Last Position

- **Difficulty:** Medium
- **Topics:** Binary Search

## Problem Statement

Given a sorted array of integers with duplicates and a target, find the starting and ending position of target. Print '-1 -1' if not found.

## Input Format

First line: n and target. Second line: n sorted integers.

## Output Format

Print two indices space-separated or '-1 -1'.

## Examples

**Example 1**

Input:
```
6 8
5 7 7 8 8 10
```

Output:
```
3 4
```

**Example 2**

Input:
```
6 6
5 7 7 8 8 10
```

Output:
```
-1 -1
```


## Constraints

- 0 <= n <= 10^5

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
