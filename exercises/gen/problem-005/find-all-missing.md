# Find All Missing

- **Difficulty:** Easy
- **Topics:** Array, Hashing

## Problem Statement

Given an array of n integers where each value is in [1, n], some elements appear twice and others once. Find all the integers in [1, n] that do not appear in the array.

## Input Format

First line: n. Second line: n space-separated integers.

## Output Format

Print the missing numbers in ascending order, space-separated (or empty output if none).

## Examples

**Example 1**

Input:
```
4
4 3 2 7 8 2 3 1
```

Output:
```
5 6
```

**Example 2**

Input:
```
2
1 1
```

Output:
```
2
```


## Constraints

- 1 <= n <= 10^5, 1 <= nums[i] <= n

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
