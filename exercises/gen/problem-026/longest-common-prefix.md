# Longest Common Prefix

- **Difficulty:** Easy
- **Topics:** Strings

## Problem Statement

Given an array of strings, find the longest common prefix among them. Return empty string if none.

## Input Format

First line: n. Next n lines: one string each (lowercase).

## Output Format

Print the longest common prefix.

## Examples

**Example 1**

Input:
```
3
flower flow flight
```

Output:
```
fl
```

**Example 2**

Input:
```
3
dog racecar car
```

Output:
```

```

**Example 3**

Input:
```
2
ab a
```

Output:
```
a
```


## Constraints

- 1 <= n <= 200, 0 <= strs[i].length <= 200

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
