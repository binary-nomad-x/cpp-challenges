# Jump Game II

- **Difficulty:** Medium
- **Topics:** Greedy, BFS

## Problem Statement

Given the same array, return the minimum number of jumps to reach the last index. Assume you can always reach the last index.

## Input Format

First line: n. Second line: n space-separated non-negative integers.

## Output Format

Print the minimum jumps.

## Examples

**Example 1**

Input:
```
5
2 3 1 1 4
```

Output:
```
2
```

**Example 2**

Input:
```
10
2 3 1 1 4 2 1 1 1 1
```

Output:
```
4
```


## Constraints

- 1 <= n <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
