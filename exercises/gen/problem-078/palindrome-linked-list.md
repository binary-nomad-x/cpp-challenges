# Palindrome Linked List

- **Difficulty:** Easy
- **Topics:** Linked List

## Problem Statement

Check whether a singly linked list is a palindrome. Print true or false.

## Input Format

First line: n. Second line: n list values.

## Output Format

Print true or false.

## Examples

**Example 1**

Input:
```
5
1 2 3 2 1
```

Output:
```
true
```

**Example 2**

Input:
```
4
1 2 3 4
```

Output:
```
false
```

**Example 3**

Input:
```
2
1 1
```

Output:
```
true
```


## Constraints

- 1 <= n <= 10^5, values 0-9

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
