# Missing Number

- **Difficulty:** Easy
- **Topics:** Array, Math, Bit Manipulation

## Problem Statement

Given an array nums of n distinct integers taken from the range [0, n], find the one number that is missing from the array.

## Input Format

First line: n. Second line: n space-separated integers.

## Output Format

Print the missing number.

## Examples

**Example 1**

Input:
```
3
3 0 1
```

Output:
```
2
```

**Example 2**

Input:
```
4
0 1 2 3
```

Output:
```
4
```

**Example 3**

Input:
```
5
9 6 4 2 3 5 7 0 1
```

Output:
```
8
```


## Constraints

- 1 <= n <= 10^4, nums contains distinct numbers from [0, n] except one

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
