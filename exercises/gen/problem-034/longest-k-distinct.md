# Longest K Distinct

- **Difficulty:** Medium
- **Topics:** Sliding Window

## Problem Statement

Given a string, find the length of the longest substring that contains at most k distinct characters.

## Input Format

First line: string s and integer k separated by space.

## Output Format

Print the length.

## Examples

**Example 1**

Input:
```
eceba 2
```

Output:
```
3
```

**Example 2**

Input:
```
aa 1
```

Output:
```
2
```

**Example 3**

Input:
```
araaci 2
```

Output:
```
4
```


## Constraints

- 1 <= s.length <= 5*10^4, 1 <= k <= 50

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
