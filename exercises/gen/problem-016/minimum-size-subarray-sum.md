# Minimum Size Subarray Sum

- **Difficulty:** Medium
- **Topics:** Sliding Window

## Problem Statement

Given an array of positive integers and a target, find the minimal length of a contiguous subarray whose sum is greater than or equal to target. Return 0 if none exists.

## Input Format

First line: n and target. Second line: n space-separated positive integers.

## Output Format

Print the minimal length.

## Examples

**Example 1**

Input:
```
6 7
2 3 1 2 4 3
```

Output:
```
2
```

**Example 2**

Input:
```
3 4
1 4 4
```

Output:
```
1
```

**Example 3**

Input:
```
5 11
1 1 1 1 1
```

Output:
```
0
```


## Constraints

- 1 <= n <= 10^5, 1 <= target <= 10^9

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
