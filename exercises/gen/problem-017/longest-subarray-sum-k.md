# Longest Subarray Sum K

- **Difficulty:** Medium
- **Topics:** Sliding Window, Hashing

## Problem Statement

Given an array of positive integers and k, find the length of the longest contiguous subarray whose sum equals k.

## Input Format

First line: n and k. Second line: n space-separated positive integers.

## Output Format

Print the longest length (0 if none).

## Examples

**Example 1**

Input:
```
5 5
1 2 3 2 1
```

Output:
```
2
```

**Example 2**

Input:
```
4 3
1 1 1 1
```

Output:
```
3
```


## Constraints

- 1 <= n <= 10^5, 1 <= nums[i], k <= 10^9

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
