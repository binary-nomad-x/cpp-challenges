# Reverse Words

- **Difficulty:** Medium
- **Topics:** Strings, Two Pointers

## Problem Statement

Given a sentence with extra spaces, reverse the order of words and return a single string with single spaces between words and no leading/trailing spaces.

## Input Format

First line: the sentence (words separated by single or multiple spaces).

## Output Format

Print the reversed sentence.

## Examples

**Example 1**

Input:
```
the sky is blue
```

Output:
```
blue is sky the
```

**Example 2**

Input:
```
  hello world  
```

Output:
```
world hello
```

**Example 3**

Input:
```
a good   example
```

Output:
```
example good a
```


## Constraints

- 1 <= s.length <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
