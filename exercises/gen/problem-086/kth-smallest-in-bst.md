# Kth Smallest in BST

- **Difficulty:** Medium
- **Topics:** Tree, Inorder

## Problem Statement

Given a BST (level-order, -1 = null) and k, return the k-th smallest element (1-based).

## Input Format

First line: n and k. Second line: n level-order values.

## Output Format

Print the k-th smallest value.

## Examples

**Example 1**

Input:
```
7 3
5 3 6 2 4 -1 -1 1
```

Output:
```
3
```

**Example 2**

Input:
```
3 2
5 3 6
```

Output:
```
5
```


## Constraints

- 1 <= k <= n <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
