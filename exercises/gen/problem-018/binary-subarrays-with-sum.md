# Binary Subarrays With Sum

- **Difficulty:** Medium
- **Topics:** Sliding Window

## Problem Statement

Given a binary array, count the number of non-empty subarrays with sum exactly equal to goal.

## Input Format

First line: n and goal. Second line: n space-separated 0s and 1s.

## Output Format

Print the count.

## Examples

**Example 1**

Input:
```
5 2
1 0 1 0 1
```

Output:
```
4
```

**Example 2**

Input:
```
3 0
0 0 0
```

Output:
```
6
```


## Constraints

- 1 <= n <= 3*10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
