# Rotate Array

- **Difficulty:** Medium
- **Topics:** Array, Reversal

## Problem Statement

Rotate the array to the right by k steps, where k is non-negative. Do it in place.

## Input Format

First line: n and k. Second line: n space-separated integers.

## Output Format

Print the rotated array space-separated.

## Examples

**Example 1**

Input:
```
7 3
1 2 3 4 5 6 7
```

Output:
```
5 6 7 1 2 3 4
```

**Example 2**

Input:
```
4 2
-1 -100 3 99
```

Output:
```
3 99 -1 -100
```


## Constraints

- 1 <= n <= 10^5, 0 <= k <= 10^5

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
