# Level Order Traversal

- **Difficulty:** Medium
- **Topics:** Tree, BFS

## Problem Statement

Given a binary tree, return its level-order traversal; print one level per line.

## Input Format

First line: n. Second line: n level-order values (-1 = null).

## Output Format

Print each level's values space-separated, one level per line.

## Examples

**Example 1**

Input:
```
7
3 9 20 -1 -1 15 7
```

Output:
```
3
9 20
15 7
```

**Example 2**

Input:
```
3
1 2 3
1
```

Output:
```
2 3
```


## Constraints

- 0 <= n <= 2000

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
