# Climbing Stairs

- **Difficulty:** Easy
- **Topics:** DP

## Problem Statement

You are climbing a staircase of n steps. Each time you can climb 1 or 2 steps. Count how many distinct ways you can reach the top.

## Input Format

First line: integer n.

## Output Format

Print the number of ways.

## Examples

**Example 1**

Input:
```
2
```

Output:
```
2
```

**Example 2**

Input:
```
3
```

Output:
```
3
```

**Example 3**

Input:
```
5
```

Output:
```
8
```


## Constraints

- 1 <= n <= 45

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
