# Invert Binary Tree

- **Difficulty:** Easy
- **Topics:** Tree, DFS

## Problem Statement

Invert a binary tree (swap every left and right subtree) and print its level-order traversal with -1 for nulls.

## Input Format

First line: n. Second line: n level-order values (-1 = null).

## Output Format

Print level-order of inverted tree (trim trailing nulls).

## Examples

**Example 1**

Input:
```
7
4 2 7 1 3 6 9
```

Output:
```
4 7 2 9 6 3 1
```

**Example 2**

Input:
```
3
2 1 3
```

Output:
```
2 3 1
```


## Constraints

- 0 <= n <= 100

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
