# Jump Game

- **Difficulty:** Medium
- **Topics:** Greedy

## Problem Statement

Given an array where nums[i] is the max jump length from index i, determine whether you can reach the last index starting from index 0.

## Input Format

First line: n. Second line: n space-separated non-negative integers.

## Output Format

Print true or false.

## Examples

**Example 1**

Input:
```
5
2 3 1 1 4
```

Output:
```
true
```

**Example 2**

Input:
```
5
3 2 1 0 4
```

Output:
```
false
```


## Constraints

- 1 <= n <= 10^4, 0 <= nums[i] <= 10^5

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
