# Longest Repeating Replacement

- **Difficulty:** Medium
- **Topics:** Sliding Window

## Problem Statement

Given a string and integer k, find the length of the longest substring containing the same letter you can get after changing at most k characters.

## Input Format

First line: string s and integer k separated by space.

## Output Format

Print the length.

## Examples

**Example 1**

Input:
```
ABAB 2
```

Output:
```
4
```

**Example 2**

Input:
```
AABABBA 1
```

Output:
```
4
```


## Constraints

- 1 <= s.length <= 10^5, uppercase letters

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
