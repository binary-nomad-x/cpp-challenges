# Basic Calculator II

- **Difficulty:** Medium
- **Topics:** Stack, Math

## Problem Statement

Given a string expression of non-negative integers and + - * / operators, evaluate it (integer division truncates toward zero).

## Input Format

First line: expression string (no spaces).

## Output Format

Print the result.

## Examples

**Example 1**

Input:
```
3+2*2
```

Output:
```
7
```

**Example 2**

Input:
```
 3/2 
```

Output:
```
1
```

**Example 3**

Input:
```
 3+5 / 2 
```

Output:
```
5
```


## Constraints

- 1 <= s.length <= 3*10^5

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
