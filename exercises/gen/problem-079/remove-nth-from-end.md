# Remove Nth From End

- **Difficulty:** Medium
- **Topics:** Linked List, Two Pointers

## Problem Statement

Given a linked list, remove the n-th node from the end and print the resulting list.

## Input Format

First line: n (list size) and k. Second line: n list values.

## Output Format

Print the list values space-separated after removal.

## Examples

**Example 1**

Input:
```
5 2
1 2 3 4 5
```

Output:
```
1 2 3 5
```

**Example 2**

Input:
```
2 1
1 2
```

Output:
```
1
```

**Example 3**

Input:
```
2 2
1 2
```

Output:
```
2
```


## Constraints

- 1 <= k <= n <= 30

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
