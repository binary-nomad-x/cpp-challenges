# Partition Labels

- **Difficulty:** Medium
- **Topics:** Greedy, Hashing

## Problem Statement

Given a string, partition it into as many parts as possible so each letter appears in at most one part. Print the sizes of the parts.

## Input Format

First line: string s (lowercase).

## Output Format

Print the part sizes space-separated.

## Examples

**Example 1**

Input:
```
ababcbacadefegdehijhklij
```

Output:
```
9 7 8
```

**Example 2**

Input:
```
eccbbbbdec
```

Output:
```
10
```


## Constraints

- 1 <= s.length <= 500

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
