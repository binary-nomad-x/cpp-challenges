# Reverse Linked List

- **Difficulty:** Easy
- **Topics:** Linked List

## Problem Statement

Given a singly linked list, reverse it and print the reversed list values space-separated.

## Input Format

First line: n. Second line: n list values.

## Output Format

Print reversed values space-separated.

## Examples

**Example 1**

Input:
```
5
1 2 3 4 5
```

Output:
```
5 4 3 2 1
```

**Example 2**

Input:
```
2
1 2
```

Output:
```
2 1
```


## Constraints

- 0 <= n <= 5000

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
