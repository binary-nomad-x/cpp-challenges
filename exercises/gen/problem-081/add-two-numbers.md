# Add Two Numbers

- **Difficulty:** Medium
- **Topics:** Linked List, Math

## Problem Statement

Two numbers are stored in reverse order in two linked lists, one digit per node. Add them and print the sum as a list.

## Input Format

First line: n m. Second line: digits of first number (reverse order). Third line: digits of second number.

## Output Format

Print the resulting digits space-separated (reverse order).

## Examples

**Example 1**

Input:
```
3 3
2 4 3
5 6 4
```

Output:
```
7 0 8
```

**Example 2**

Input:
```
3 3
9 9 9
9 9 9
```

Output:
```
8 9 9 1
```

**Example 3**

Input:
```
1 2
0
5 7
```

Output:
```
5 7
```


## Constraints

- 1 <= n, m <= 100

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
