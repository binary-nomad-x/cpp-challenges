# Integer Sqrt

- **Difficulty:** Easy
- **Topics:** Binary Search

## Problem Statement

Given a non-negative integer x, compute and return the integer square root of x (floor of sqrt(x)).

## Input Format

First line: integer x.

## Output Format

Print the integer square root.

## Examples

**Example 1**

Input:
```
4
```

Output:
```
2
```

**Example 2**

Input:
```
8
```

Output:
```
2
```

**Example 3**

Input:
```
2147395600
```

Output:
```
46340
```


## Constraints

- 0 <= x <= 2^31 - 1

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
