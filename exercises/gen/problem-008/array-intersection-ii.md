# Array Intersection II

- **Difficulty:** Easy
- **Topics:** Hashing, Two Pointers

## Problem Statement

Given two integer arrays, return an array of their intersection. Each element in the result must appear as many times as it appears in both arrays.

## Input Format

First line: n and m. Second line: n integers. Third line: m integers.

## Output Format

Print the intersection elements space-separated (any order).

## Examples

**Example 1**

Input:
```
4 5
1 2 2 1
2 2
```

Output:
```
2 2
```

**Example 2**

Input:
```
3 3
4 9 5
9 4 9 8 4
```

Output:
```
4 9
```


## Constraints

- 1 <= n, m <= 1000

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
