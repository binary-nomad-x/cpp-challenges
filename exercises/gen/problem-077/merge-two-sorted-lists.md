# Merge Two Sorted Lists

- **Difficulty:** Easy
- **Topics:** Linked List

## Problem Statement

Merge two sorted linked lists into one sorted list and print it space-separated.

## Input Format

First line: n m. Second line: n values of first list. Third line: m values of second list.

## Output Format

Print the merged list values space-separated.

## Examples

**Example 1**

Input:
```
3 3
1 2 4
1 3 4
```

Output:
```
1 1 2 3 4 4
```

**Example 2**

Input:
```
2 0
1 3


```

Output:
```
1 3
```


## Constraints

- 0 <= n, m <= 50

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
