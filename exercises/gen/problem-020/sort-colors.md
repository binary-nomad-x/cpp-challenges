# Sort Colors

- **Difficulty:** Medium
- **Topics:** Two Pointers

## Problem Statement

Given an array with n objects colored red (0), white (1), or blue (2), sort them in place so objects of the same color are adjacent in the order red, white, blue. Use one pass.

## Input Format

First line: n. Second line: n integers in {0,1,2}.

## Output Format

Print the sorted array space-separated.

## Examples

**Example 1**

Input:
```
6
2 0 2 1 1 0
```

Output:
```
0 0 1 1 2 2
```

**Example 2**

Input:
```
3
2 0 1
```

Output:
```
0 1 2
```


## Constraints

- 1 <= n <= 300

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
