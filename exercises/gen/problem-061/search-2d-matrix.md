# Search 2D Matrix

- **Difficulty:** Medium
- **Topics:** Binary Search

## Problem Statement

Given an m x n matrix where each row is sorted and the first element of each row is greater than the last of the previous row, search for a target. Print true or false.

## Input Format

First line: m and n. Next m lines: n integers each. Last line: target.

## Output Format

Print true or false.

## Examples

**Example 1**

Input:
```
3 4
1 3 5 7
10 11 16 20
23 30 34 60
3
```

Output:
```
true
```

**Example 2**

Input:
```
3 4
1 3 5 7
10 11 16 20
23 30 34 60
13
```

Output:
```
false
```


## Constraints

- 1 <= m, n <= 100

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
