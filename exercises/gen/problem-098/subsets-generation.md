# Subsets Generation

- **Difficulty:** Medium
- **Topics:** Backtracking

## Problem Statement

Given an array of distinct integers, return all possible subsets (the power set), each subset on its own line, elements space-separated (empty subset as blank line allowed).

## Input Format

First line: n. Second line: n distinct integers.

## Output Format

Print all subsets, one per line, any order.

## Examples

**Example 1**

Input:
```
3
1 2 3

1
2
1 2
3
1 3
2 3
```

Output:
```
1 2 3
```

**Example 2**

Input:
```
1
0

```

Output:
```
0
```


## Constraints

- 1 <= n <= 10

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
