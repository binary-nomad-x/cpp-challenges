# Island Perimeter

- **Difficulty:** Easy
- **Topics:** Graph

## Problem Statement

Given a single-island binary grid, compute its perimeter.

## Input Format

First line: m and n. Next m lines: n characters (0/1).

## Output Format

Print the perimeter.

## Examples

**Example 1**

Input:
```
4 4
1100
1110
0110
0010
```

Output:
```
14
```

**Example 2**

Input:
```
1 1
1
```

Output:
```
4
```

**Example 3**

Input:
```
1 2
11
```

Output:
```
6
```


## Constraints

- 1 <= m, n <= 100

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
