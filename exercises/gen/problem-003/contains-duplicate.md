# Contains Duplicate

- **Difficulty:** Easy
- **Topics:** Array, Hashing

## Problem Statement

Given an integer array, determine whether any value appears at least twice.

## Input Format

First line: n. Second line: n space-separated integers.

## Output Format

Print true if a duplicate exists, otherwise false.

## Examples

**Example 1**

Input:
```
4
1 2 3 1
```

Output:
```
true
```

**Example 2**

Input:
```
4
1 2 3 4
```

Output:
```
false
```


## Constraints

- 1 <= n <= 10^5, -10^9 <= nums[i] <= 10^9

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
