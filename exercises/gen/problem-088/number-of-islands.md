# Number of Islands

- **Difficulty:** Medium
- **Topics:** Graph, DFS, BFS

## Problem Statement

Given an m x n grid of '1' (land) and '0' (water), count the number of islands (4-directionally connected land).

## Input Format

First line: m and n. Next m lines: n characters each with no spaces.

## Output Format

Print the number of islands.

## Examples

**Example 1**

Input:
```
4 5
11000
11000
00100
00011
```

Output:
```
3
```

**Example 2**

Input:
```
1 1
1
```

Output:
```
1
```

**Example 3**

Input:
```
3 3
111
010
111
```

Output:
```
1
```


## Constraints

- 1 <= m, n <= 300

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
