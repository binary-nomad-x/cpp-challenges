# Anagrams in String

- **Difficulty:** Medium
- **Topics:** Sliding Window, Hashing

## Problem Statement

Given strings s and p, find all starting indices of p's anagrams in s. Print indices in ascending order.

## Input Format

First line: strings s and p separated by a space.

## Output Format

Print indices space-separated (empty if none).

## Examples

**Example 1**

Input:
```
cbaebabacd ab
```

Output:
```
0 6
```

**Example 2**

Input:
```
abab ab
```

Output:
```
0 1 2
```


## Constraints

- 1 <= p.length <= s.length <= 3*10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
