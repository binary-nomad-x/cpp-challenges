# Binary Search Basic

- **Difficulty:** Easy
- **Topics:** Binary Search

## Problem Statement

Given a sorted array and a target, return the index of target or -1 if not present.

## Input Format

First line: n and target. Second line: n sorted integers.

## Output Format

Print the index or -1.

## Examples

**Example 1**

Input:
```
6 9
-1 0 3 5 9 12
```

Output:
```
4
```

**Example 2**

Input:
```
6 2
-1 0 3 5 9 12
```

Output:
```
-1
```


## Constraints

- 1 <= n <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
