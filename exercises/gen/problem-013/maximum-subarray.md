# Maximum Subarray

- **Difficulty:** Medium
- **Topics:** DP, Kadane

## Problem Statement

Given an integer array, find the contiguous subarray with the largest sum and return its sum.

## Input Format

First line: n. Second line: n space-separated integers.

## Output Format

Print the maximum subarray sum.

## Examples

**Example 1**

Input:
```
9
-2 1 -3 4 -1 2 1 -5 4
```

Output:
```
6
```

**Example 2**

Input:
```
1
1
```

Output:
```
1
```

**Example 3**

Input:
```
5
5 4 -1 7 8
```

Output:
```
23
```


## Constraints

- 1 <= n <= 10^5, -10^4 <= nums[i] <= 10^4

---

**Your Task:** Solve this problem in **C++ (C++17)**. Read input from standard input and write the answer to standard output. Do not include explanations — only the required output.
